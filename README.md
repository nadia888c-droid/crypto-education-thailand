My Capstone Project is a website designed to teach teenagers the basics of cryptocurrency in a simple and safe way. The website will include short lessons written in easy-to-understand language, with a quiz after each section to check understanding. It will also feature interactive tools such as a glossary and a chatbot to help explain key terms. The project is aimed at teens who are new to cryptocurrency and want a clear introduction without being overwhelmed.

Most cryptocurrency websites are complex and targeted at adults, which makes them difficult and risky for teenagers to use. This project provides a teen-focused learning platform that explains crypto clearly and helps users avoid scams before they encounter them in real life.

This project benefits teenagers by giving them accessible financial and technological knowledge in a format designed for their age group. The interactive elements help keep students engaged and make learning more effective.

This project combines my interest in cryptocurrency and finance with web design and technology. It also involves education and communication skills by turning complex topics into clear lessons for beginners.

I will measure impact using website analytics, such as the number of visitors, time spent on pages, and quiz completion rates. Feedback from students who use the website will also be used to evaluate understanding and engagement.
